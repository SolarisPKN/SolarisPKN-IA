# Notice

This public edition was rewritten as a clean-room, vendor-neutral reference from the architectural concepts of SolarisPKN-IA.

It intentionally does **not** bundle:

- source files from external agent frameworks;
- vendor SDK source code;
- external model weights;
- third-party application assets;
- copied documentation from external companies;
- private user data or private runtime artifacts.

External systems can be connected later through standard adapter contracts such as HTTP, WebSocket, CLI processes, OAuth/OIDC, or MCP. Those integrations are not part of this distribution.
