# Privacy

A public blueprint should never contain the private brain of a real assistant.

Keep outside version control:

- conversation history;
- long-term personal memory;
- biometric templates;
- custom personality files;
- health information;
- private project context;
- local machine paths;
- account identifiers;
- API tokens and cookies;
- device pairing secrets;
- voice/face recognition data;
- private automation rules.

Use a separate local data root and include only synthetic examples in public repositories.
