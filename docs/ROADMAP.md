# Suggested implementation roadmap

A practical sequence for an independent implementation:

1. **Baseline + privacy boundary** — config, local data root, no secrets in source.
2. **Sessions** — append-only event log and crash recovery.
3. **Capabilities** — provider registry and profiles.
4. **Read-only tools** — files/search/memory.
5. **Policy + approvals** — before any external effects.
6. **Memory + retrieval** — provenance and lifecycle.
7. **Natural tool broker** — chat-first automatic selection.
8. **Review + verification** — separate candidate generation from acceptance.
9. **Provider failover** — local/remote replacements.
10. **Learning + skills** — candidate knowledge and reviewed procedures.
11. **Scheduler + subagents** — bounded background/delegated work.
12. **Gateway + nodes** — channels/devices after the core is hardened.
13. **Voice + embodiment** — transport/presence over the same runtime.
14. **Application engineering** — build/test/portable project workflows.
15. **Creative/media adapters** — typed high-level capabilities.
16. **Diagnostics + live state** — doctor and generated state manifest.
17. **Public export pipeline** — sanitize architecture separately from private state.
