# Learning system

A Solaris-like assistant can learn without silently rewriting itself.

## Teacher contract

A learning provider can expose:

- explain a concept;
- diagnose an error;
- search a curriculum;
- generate an exercise;
- evaluate an answer;
- recommend the next topic;
- report progress.

## Local authority

The external provider is a teacher, not the memory authority.

All proposed knowledge enters locally as:

```text
candidate
```

It can advance only with evidence:

```text
candidate -> validated -> practiced -> verified -> mastered
```

## Procedural skills

Learning a procedure should create a draft skill with provenance and tests. Promotion to active status is a separate reviewed transition.
