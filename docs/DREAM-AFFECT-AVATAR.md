# Dream, functional affect and avatar state

These three systems are observable control layers. None of them imply biological emotion or consciousness.

## Dream / reflection cycle

A bounded reflection cycle may:

1. inspect recent event summaries;
2. retrieve selected memory/knowledge;
3. inspect unresolved questions and note links;
4. propose connections, contradictions or follow-up questions;
5. write a Markdown **reflection candidate** to the assistant vault.

It must **not** automatically promote new factual claims to durable truth or expand permissions.

## Functional affect

A practical state vector may contain 0–100 values such as:

- happiness;
- sadness;
- anger;
- curiosity;
- calm;
- frustration;
- confidence;
- energy;
- social warmth.

These numbers can influence tone, attention, exploration budget, animation or UI. They cannot change factual evidence, policy, approvals or security boundaries.

Updates should be explainable: task success may increase confidence/calm; repeated failure may increase frustration; new useful evidence may increase curiosity. Values decay toward configurable baselines.

## Avatar / embodiment

An avatar is a presentation adapter over assistant state.

Safe examples:

- idle/walking/working/sleeping states;
- look toward pointer coordinates;
- bounded idle actions such as walk/pause/hop/peek;
- speech bubble/lip-sync hooks;
- mood-linked visual theme;
- draggable window;
- open control center on interaction.

Camera-based gaze, game control, keyboard/mouse injection and process injection are **separate capabilities**, never implied by drawing an avatar.
