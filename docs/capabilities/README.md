## Status language

- `SPECIFIED`: a concrete architecture/contract exists in the reference design.
- `NEEDS_ADAPTER`: the concept is specified but requires a concrete implementation, benchmark, integration, or environment.
- `EXTERNAL`: the capability requires real hardware, a real account/service, or explicit credentials and must not be faked.

For how all of these fit together as one system, read [../FULL-SYSTEM-SPEC.md](../FULL-SYSTEM-SPEC.md).
